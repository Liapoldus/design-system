# Иконки

Все значки используют `viewBox="0 0 24 24"`, Forest-контур и Yarn Orange или
Apricot как ограниченный акцент. Геометрия рассчитана на размеры 16–32 px;
для меньших размеров следует проверять толщину штриха отдельно.

Для светлой поверхности используются SVG из каталога `icons/`, для тёмной —
соответствующая копия из `icons/on-dark/`. Семантика и имена файлов совпадают.
Иконки пакета предназначены для продуктовой и экосистемной графики; элементы
управления интерфейсом могут продолжать использовать специализированный UI-пак.
