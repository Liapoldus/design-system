основной контур — Forest. Имена являются стабильным API пакета.

| `settings.svg` | Настройки |
| `terminal.svg` | CLI / консоль |
| `metrics.svg` | Метрики |
| `database.svg` | Хранилище |
| `cloud.svg` | Cloud target |
| `shield.svg` | Security / trust |
| `plug.svg` | Plugin |

| `sliders.svg` | Конфигурация |
