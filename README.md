# Liapoldus Design System

Общие бренд-материалы и визуальные основы экосистемы Liapoldus: логотип,
цветовые и типографические токены, иллюстрации маскота и SVG-пак иконок.

Пакет не привязан к UI-фреймворку. SVG и CSS-токены можно использовать в
desktop-приложениях, документации и web-продуктах экосистемы. Для Studio
публикуется версионированный автономный snapshot — сборка Studio не зависит от
локального checkout этого репозитория.

## Установка

После публикации пакета в npm:

```sh
npm install @liapoldus/design-system
```

Импорт токенов:

```css
@import "@liapoldus/design-system/tokens.css";
```

Статические ресурсы доступны через exports `./logo/*`, `./icons/*` и
`./mascots/*`. До публикации пакет можно подключить локально для разработки,
но потребители должны фиксировать опубликованную версию, а не зависеть от
соседней директории.

## Состав

- `assets/logo/` — горизонтальный, вертикальный и компактный знаки;
- `assets/icons/` — единый SVG-набор для инструментов экосистемы;
- `assets/mascots/` — отдельные прозрачные иллюстрации маскота;
- `tokens/tokens.css` — CSS custom properties для light/dark тем;
- `tokens/tokens.json` — машинно-читаемые исходные значения;
- `docs/style-guide.md` — применение бренда и правила интерфейса.

## Версионирование

Изменение цветов, шрифтов, геометрии логотипа или существующего имени токена
считается breaking change и требует новой major-версии. Новые токены и иконки
добавляются в minor-релиз. Исправления, не меняющие визуальный контракт,
выпускаются как patch. Имена опубликованных иконок не переиспользуются для
другой семантики.
