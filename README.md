# Liapoldus Design System

Общие бренд-материалы и визуальные основы экосистемы Liapoldus: логотипы,
иконки продуктов, локальная гарнитура, токены и векторные сцены маскота.
Пакет не зависит от UI-фреймворка и подходит для desktop, документации и web.

Studio использует автономный проверяемый snapshot, поэтому её сборка не требует
локального checkout этого репозитория.

## Установка и подключение

После публикации пакета:

```sh
npm install @liapoldus/design-system
```

Подключите локальную гарнитуру и CSS-токены:

```css
@import "@liapoldus/design-system/fonts.css";
@import "@liapoldus/design-system/tokens.css";
```

Статические ресурсы доступны через exports `./logo/*`, `./icons/*`,
`./mascots/*` и `./fonts/*`. Иконки на тёмном фоне лежат в `icons/on-dark/`.
Пакет содержит оптимизированные публикационные SVG; редактируемые мастера
находятся в `assets/` репозитория.

## Каталоги

- `assets/logo/` — варианты знака, локапов и исходники app icons;
- `assets/icons/` — 24 семантические иконки и варианты для тёмной поверхности;
- `assets/mascots/` — пять SVG-сцен и совместимые PNG-экспорты;
- `assets/fonts/` — переменная гарнитура Onest и лицензия OFL;
- `tokens/` — CSS custom properties и машинно-читаемые токены;
- `docs/style-guide.md` — применение бренда.

## Сборка и проверка

```sh
npm install
npm run build:assets
npm run check:svg
npm pack --dry-run
```

Для raster build требуется `librsvg` (`rsvg-convert`); оптимизация использует
закреплённую версию SVGO. SVG-проверка проверяет XML, viewBox, доступные заголовки,
внешние ссылки и успешный рендер каждого исходника и пакуемой копии.

## Версионирование

Изменение цветов, шрифтов, геометрии логотипа или существующего имени токена —
breaking change и требует major-версии. Новые иконки добавляются без изменения
семантики опубликованных имён. Эта переработка подготавливает локальный пакет
`1.0.0`; публикация выполняется отдельно.
